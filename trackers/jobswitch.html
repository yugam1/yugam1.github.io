On AI in 2026 interviews — what changed
  • AI-allowed coding is no longer fringe. Google is piloting it. Meta and Shopify run it for some roles. ~62% of companies still ban it. Prep for both: whiteboard from scratch and AI-collaborative direction.
  • "AI fluency" is being assessed. Your Cursor/Claude workflow at NPM is interview material now — document it consciously through Modules 1–2.
  • GenAI system design rounds are mainstream for senior backend IC, not just ML. RAG, vector DBs, LLM serving economics, eval, guardrails. Module 1 Week 5 covers fundamentals; Module 2 goes deep; Module 3 has you build a working RAG system.
  • Your edge: trace context propagation, structured logging, Kafka hardening — all transfer 1:1 to "I can ship reliable AI systems too". The RAG build in Module 3 makes this concrete.

Security model: Your sync code holds a PAT. Treat it like a password. Stored only in this browser's localStorage; only ever sent to api.github.com.

Recommended PAT: Fine-grained (not classic) · Gists · Read+Write only · 30–90 day expiry.

If sync code leaks: revoke the PAT at github.com/settings/tokens. The gist stays. Create a new PAT, generate a new sync code, re-paste on each device. Worst case (gist-only scope), an attacker reads/writes just your gists.

Want zero per-device setup? That requires a backend holding the PAT (Cloudflare Worker, Vercel function). About 50 lines of Worker code + leaving GitHub Pages. Not worth it until you have many devices.
How Quick / Load work: Your state is JSON, compressed with lz-string, URL-safe base64 encoded. The QR just transports the text visually. Nothing leaves your devices except whatever you send to yourself.

Last-write-wins: importing replaces this device's state. If you've made changes on both devices since last sync, the one you import will overwrite the other.

Want it automatic? See the Continuous tab — auto-syncs every change to a private GitHub Gist.
